Overview
This is a Go boilerplate project that provides a basic structure for building a scalable Go application. It includes configuration for connecting to a PostgreSQL database, running APIs, and setting up Docker containers for development and production environments.

Features
* Built with Go
* PostgreSQL as the database
* Docker and Docker Compose setup for easy deployment
* Basic structure for a clean and scalable Go application
* API routing using chi
* GORM as the ORM for database interactions
